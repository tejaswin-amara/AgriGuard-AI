# AgriGuard AI — Completion & Current-State Report

> **Snapshot date:** 2026-09-30  
> **Branch:** `main`  
> **Application version in FastAPI:** `2.0.0`

## 1. What is implemented

### Backend

The repository contains a FastAPI application with:

- farm and location endpoints;
- weather and historical climate endpoints;
- optional environmental/biodiversity/news endpoints;
- disease image-analysis endpoint;
- soil-analysis endpoint;
- grounded advisory generation;
- advisory history;
- provider health diagnostics;
- SQLModel persistence;
- PostgreSQL Compose support;
- typed Pydantic response contracts.

### Frontend

The React application contains:

- farm intelligence dashboard;
- farm setup;
- soil health analysis;
- crop leaf disease inference;
- insights;
- advisory history;
- Responsible AI page;
- About page.

### ML

**Disease:** MobileNetV2 architecture definition exists, but the active inference path is deterministic demo logic and does not load trained weights.

**Soil:** XGBoost classifier is trained from 1,000 synthetic samples generated by heuristic rules. The model artifact is generated locally.

### RAG / LLM

- Markdown demo corpus;
- ChromaDB persistent retrieval;
- sentence-transformer embeddings;
- evidence-required advisory boundary;
- local deterministic advisory provider;
- optional IBM watsonx.ai / Granite provider.

### Infrastructure

- PostgreSQL 16;
- MinIO;
- FastAPI;
- frontend Nginx container;
- GitHub Actions;
- Dependabot;
- Gitleaks;
- Trivy.

## 3. Database and migration status

The repository includes Alembic configuration and an initial migration revision.

The current FastAPI application startup code still calls SQLModel table creation directly. Alembic is therefore present as a migration framework, but the active Compose startup path should not be described as “Alembic-only”.

## 4. Prototype limitations

- Disease model is not field validated.
- Soil model is trained on synthetic heuristic data.
- RAG corpus is limited to three demo documents.
- News data is currently static/curated.
- Some external-provider failures use deterministic fallbacks.
- No authentication or authorization exists.
- No rate limiting exists.
- MinIO is provisioned but the disease API does not currently store uploaded bytes through the MinIO client.
- Frontend relative API requests require compatible routing; the shipped Nginx image does not contain an API reverse-proxy configuration.
- No production deployment or recovery environment is implemented.

## 5. Responsible-AI boundaries

The project exposes provenance, freshness, model/demo limitations, citations, and qualitative risk explanations.

The advisory layer does not generate an evidence-backed recommendation when retrieval returns no usable evidence.

Prototype outputs must not be represented as field diagnosis, calibrated probability, fertilizer prescription, or agronomic guarantee.
