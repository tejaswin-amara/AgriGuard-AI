# Contributing to AgriGuard AI

Thank you for your interest in contributing to AgriGuard AI!

## Getting Started
Please see our [README](README.md) for local setup instructions.

## Development Workflow
1. Fork the repository and create your branch from `main`.
2. Follow the issue templates in `.github/ISSUE_TEMPLATE` to report bugs or request features.
3. Use conventional commits for your commit messages.
4. Open a Pull Request and use the provided PR template.

## Code Quality
- We use `biome` for frontend linting and formatting.
- We use `ruff` for backend Python linting and formatting.
- Ensure all tests pass before submitting a PR.
