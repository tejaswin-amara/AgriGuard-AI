# Changelog

All notable changes to this project are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/), commit history follows [Conventional Commits](https://www.conventionalcommits.org/).

## [2.0.0] - 2026-09-26 — Production Hardening & Repository Fixes

### Fixed
- **Advisory History API Contract**: Corrected resource route naming at source to `POST /api/v1/advisory/generate`, `GET /api/v1/advisories`, and `GET /api/v1/advisories/{id}`.
- **Geocoding Data Integrity**: Deleted hardcoded Nizamabad fallback coordinates (`18.67, 78.09`). Implemented strict HTTP 400 error handling when geocoding fails and added coordinate boundary checks `[-90, 90]` and `[-180, 180]`.
- **External Provider Failure Semantics**: Prevented unavailable providers from manufacturing fake measurements. OpenAQ API failures now report `UNAVAILABLE` instead of synthetic PM values. NASA POWER removed uncalibrated `- 80.0` anomaly calculation. Reclassified news provider as static curated bulletins with preserved metadata.
- **ML Confidence Semantics**: Explicitly set `confidence = None` for demo disease outputs and missing soil model states to avoid false statistical confidence claims.
- **Risk Engine Data Integrity**: Updated risk evaluation to output `insufficient_data` when weather or climate inputs are missing, rather than defaulting to low risk.
- **RAG Grounding Boundary**: Enforced strict evidence requirement. If no evidence is retrieved, recommendations are withheld. Removed fake fallback citation URLs (`https://icar.org.in/`) and generic organization defaults.
- **CORS Hardening**: Restricted CORS allowed origins to explicit local/production hosts rather than wildcard `["*"]` with credentials.
- **Frontend Type Safety**: Replaced all `any` types with `unknown` type guards. Synchronized TypeScript interfaces with backend Pydantic models.
- **Import Cleanup**: Removed `sys.path.append` path hacks across services. Configured clean module import resolution via `conftest.py` and `PYTHONPATH`.

### Added
- **Database Migrations**: Initialized Alembic schema migration framework (`backend/alembic/`) with autogenerated initial schema revision and foreign key indexing on `farm_id`.
- **Database Integration Tests**: Added relational SQLModel & SQLite/PostgreSQL integration tests.
- **E2E Testing**: Expanded Playwright E2E suite covering main farmer journeys (Dashboard, Farm setup, Soil analysis, Disease inference, Advisory history, Responsible AI) with deterministic API boundary mocking.
- **RAG Grounding & Security Tests**: Added unit tests verifying grounding boundaries and prompt injection safety.
